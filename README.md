# Download speed benchmark

Небольшой консольный скрипт на Python для оценки эффективной скорости скачивания файла по HTTP(S).

## Требования

Python 3.10+; внешние библиотеки не нужны.

## Запуск

```bash
python3 download_speed.py "https://example.com/large-image.jpg"
```

Можно задать таймаут ожидания HTTP-операций:

```bash
python3 download_speed.py "https://example.com/large-image.jpg" --timeout 60
```

Скрипт делает **ровно 10 последовательных GET-запросов**. Для каждого запроса он полностью считывает тело ответа порциями по 64 КиБ, не сохраняя файл на диск и не загружая целиком в оперативную память. Следующий запрос начинается после завершения предыдущего.

## Вывод

```text
URL: https://example.com/large-image.jpg
Запросов: 10 (последовательно)
Среднее время запроса: 0.500 с
Скачано: 10485760 Б (10.00 МиБ)
Средняя скорость скачивания: 2.00 МиБ/с
```

Пример иллюстративный, числа не являются результатом реального измерения.

**Единицы:**

- Время — секунды (`с`).
- Объём — байты (`Б`) и мебибайты (`МиБ`), где 1 МиБ = 1 048 576 байт.
- Скорость — **МиБ/с** (мебибайты в секунду).

**Расчёт:**

- Среднее время запроса = сумма 10 измеренных длительностей / 10.
- Общий объём = сумма количества байтов, полученных в телах всех 10 ответов.
- Средняя скорость = общий объём в МиБ / сумма длительностей всех запросов в секундах.

Время каждого запроса включает установление соединения, получение заголовков и полное чтение тела ответа. Это **эффективная скорость выполнения запросов**, а не чистая скорость сетевого интерфейса. HTTP-заголовки и накладные расходы протокола в объём не включаются.

Скрипт отправляет `Cache-Control: no-cache` и `Accept-Encoding: identity`, но сервер или промежуточный кеш не обязан гарантировать отсутствие кеширования; результат может зависеть от сервера, CDN и локального кеша. При ошибке одного запроса выполнение прекращается с ненулевым кодом возврата.

`--timeout` задаёт таймаут блокирующих сетевых операций, а не жёсткое ограничение всей загрузки.
